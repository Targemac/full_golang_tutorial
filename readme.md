## install golang
```bash
https://go.dev/
```

## create project root directory
```bash
mkdir full_golang_tutorial
```

## create `main.go` in root
```bash
touch main.go
```

## in root, run 
```bash
go mod init full_golang_tutorial
```

## in root, run the below, `go.mod` file is created
```bash
go.mod
```

## to run the program
```bash
go run .
```

## to build the program for run (this would create a binary file)
```bash
go build
```

## run the binary
```bash
./full_golang_tutorial
```
